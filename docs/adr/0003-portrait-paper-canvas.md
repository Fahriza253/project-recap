# Portrait paper canvas for the Portofolio Deck

Every recap screenshot is a portrait phone capture. A 16:9 landscape pitch canvas would shrink those images, so the deck canvas is portrait 9:16. Each bukti slide shows the screenshot whole and large, with its existing caption underneath. The palette is warm paper and ink only; application colors appear solely inside screenshots. Type is one system sans in three sizes. Navigation is previous, next, arrow keys, and a position counter, with no autoplay.

## Considered Options

- A 16:9 landscape slide with the caption beside the phone. Rejected because the caption stays below the screenshot, and a landscape frame shrinks a portrait capture.
- A separate brand color for each proyek. Rejected because the deck is one portfolio. Each application already shows its own colors inside its screenshots.
