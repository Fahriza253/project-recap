# Portofolio Deck replaces the formal recap bundle

The course deliverable was specified as a formal recap: one markdown file per project, merged, then exported to Word and PDF. That bundle reads as a report. The finished apps are shown in one Portofolio Deck in a personal-portfolio voice, with one bagian for each proyek. Who the deck is for is refined in ADR 0002. The per-project recaps stay the factual source. The deck is one HTML file opened in a browser. A merged Word or PDF document is no longer an output.

## Considered Options

- Merged formal document, exported to Word and PDF. Rejected because it is a report, not a showing of the work.
- A pitch deck that asks the examiner for a decision. Rejected because nothing is being requested; the deck only shows projects already built.
