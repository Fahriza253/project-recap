# Dokumentasi repositori

Isi `docs/` dikelompokkan per peran. Root repositori hanya menampung titik masuk (`README.md`, `AGENTS.md`, `index.html`, `LICENSE`, dan berkas konfigurasi).

| Folder | Isi |
|--------|-----|
| [`domain/`](domain/) | Bahasa domain: [`GLOSSARY.md`](domain/GLOSSARY.md) |
| [`guides/`](guides/) | Aturan penulisan Recap dan sistematika Portofolio Deck |
| [`design/`](design/) | Sistem visual deck ([`DECK_SYSTEM.md`](design/DECK_SYSTEM.md)), sumber token Notion, taste skill |
| [`profile/`](profile/) | Fakta **Identitas** Mahasiswa (sumber tunggal untuk deck) |
| [`project_*/`](.) | **Recap** per **Proyek** (teks + screenshot) |
| [`adr/`](adr/) | Keputusan arsitektur dokumentasi dan keluaran |
| [`agents/`](agents/) | Konvensi untuk agen (issue tracker, triage, domain docs) |

Keluaran deck: buka [`../index.html`](../index.html) di browser (bukan lagi di bawah `docs/portofolio-deck/`).
